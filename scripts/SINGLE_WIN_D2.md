# YS4 単勝 D2 ロジック

## 目的
- 全予想対象レースで本命の単勝を100円購入する前提を維持する。
- 単勝回収率100%以上を目標にする。
- 危険馬判定・選定頭数は変更しない。
- 三連単回収率と本命の3着内率を大きく毀損する設定は採用しない。
- 当日単勝オッズ、実人気、馬体重・増減は入力に使用しない。

## D2 の考え方
本命候補ごとに以下を別々に推定する。
1. `P(win)` = 勝つ確率
2. `P(top3)` = 3着内確率（安定性ガード）
3. `E(payout | win)` = 勝った場合の100円単勝払戻倍率

`EV = P(win) × E(payout | win)` を中心に、本命候補の総合指数差・3着内確率・旧singleEVを弱い正則化として加える。
本命候補は従来ロジックで選ばれた頭数の中だけで再順位付けする。

## 検証
`optimize_single_win_d2.py` は日付単位の expanding-window 方式で、必ず `学習日 < 対象日` とする。
OOF予測が作れた日を古い70%（調整）と新しい30%（未使用holdout）に分ける。
方針のgrid searchは70%側だけで行い、最後の30%は固定した方針を1回評価する。

採用条件:
- holdout単勝回収率を最重要視
- 3着内率がbaseline比 -3ptを超えて悪化しない
- 三連単回収率がbaseline比 -5ptを超えて悪化しない
- 単勝払戻上位3件だけで総単勝払戻の45%以上を占める設定を避ける
- 方針探索では50倍超の単勝払戻を50倍でwinsorizeした回収率を第一目的にして、大穴1件依存を抑える

## 実行
```bash
python scripts/optimize_single_win_d2.py
```

生成物:
- `data/single_win_d2_model.joblib`
- `data/single_win_d2_metrics.json`

`goalReachedOnUntouchedHoldout: true` が最初の重要判定。
100%を超えても、月別・3着内率・三連単回収率・払戻集中度を合わせて確認してからcandidateへ統合する。
