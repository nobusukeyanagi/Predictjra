# Predictjra 単勝 D3

D2の実データ検証で、現行本番の全履歴単回収率72.2%に対し、D2はモデル評価対象1,975レースで77.4%、未使用ホールドアウト608レースで74.49%まで改善しましたが、100%には届きませんでした。

D3はD2の「勝率モデルにも想定人気を入れ、払戻モデルでも人気を使う」構造を廃止します。

## D3の中心思想

1. **能力勝率モデル**
   - 近走、今走、走・展・力、総合、順位差、馬場・距離などだけを使用
   - 想定人気は入れない
2. **市場基準モデル**
   - 過去の「想定人気順位 × 頭数帯」ごとの勝率を縮約推定
3. **割安度**
   - `能力P(win) / 市場基準P(win)`
4. **払戻モデルを廃止**
   - 機械学習で払戻金を直接当てない
   - 過去の想定人気帯ごとの勝馬払戻を50倍までWinsorizeし、階層的に縮約した平均を使用
5. **時系列適応**
   - 学習データは120日半減期で重み付け
   - 直近120日の補助モデルを30%ブレンド（十分なサンプルがある場合のみ）
6. **最適化の目的を変更**
   - 全体ROIだけでなく、月別ROIの下位25%も重視
   - 6月だけ極端に崩れるようなロジックを選びにくくする

## 禁止入力

- 当該レースの現在オッズ
- 当該レースの実人気
- 馬体重
- 馬体重増減
- 同日・未来の結果ラベル

過去の確定払戻・結果は、対象日より前の日付だけを学習ラベルとして使用します。

## 実行

```bash
python scripts/optimize_single_win_d3.py
```

出力:

- `data/single_win_d3_model.joblib`
- `data/single_win_d3_metrics.json`

本番ロジックは自動変更しません。

## 採用判定

未使用ホールドアウトで以下を満たした場合にのみ本番候補とします。

- 単勝回収率が現行ベースラインより5pt以上改善
- 本命3着内率40%以上
- 三連単回収率100%以上
- 単勝払戻上位3件への依存率35%以下

単勝回収率100%は目標ですが、最適化で無理に100%を作ることはしません。
