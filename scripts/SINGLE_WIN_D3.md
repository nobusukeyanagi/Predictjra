# Predictjra 単勝 D3.1（v71）

D3の考え方は維持しつつ、単勝回収率 **80%を最低ライン** として少しずつ改善する版です。

## v71で追加した点

1. **価値差ゲート**
   - まず能力勝率・3着内率が安定している馬を「アンカー」にする
   - 割安馬へ本命を変更するのは、`edge` と `D3 EV` が最低値を超え、さらにアンカーより一定割合以上強い時だけ
   - 想定人気5位以下へ変更する場合は、人気が下がるほど必要な優位差を少し大きくする
2. **全レース購入向けの守り**
   - 毎レース100円を必ず買うため、「価値馬が弱いのに無理に穴へ行く」挙動を抑制
   - 価値差が小さいレースでは能力勝率の高い馬へ戻す
3. **80%フロア最適化**
   - optimizer の標準目標を100%から80%へ変更
   - 全体だけでなく月別下位25%と、時系列5分割の下位25%も評価
   - 80%からの不足幅を明示的に罰する
4. **探索数を増やしすぎない**
   - 新しいゲート条件を追加する一方、既存グリッドを整理し、約4,608条件に抑制

## 禁止入力は従来どおり

- 当該レースの現在オッズ
- 当該レースの実人気
- 馬体重・増減
- 同日・未来の結果ラベル

## 実行

```bash
python scripts/optimize_single_win_d3.py
```

標準の目標単勝回収率は **80%** です。

出力:
- `data/single_win_d3_model.joblib`
- `data/single_win_d3_metrics.json`

## 本番候補条件

未使用ホールドアウトで以下をすべて満たす場合のみ候補にします。

- 単勝回収率80%以上
- 現行ベースラインより5pt以上改善
- 本命3着内率40%以上
- 三連単回収率100%以上
- 単勝払戻上位3件への依存率35%以下

80%は検証目標であり、結果を後付けで80%に合わせることはしません。未使用ホールドアウトで確認します。
